# Speedi — مسابقه‌ی شبانه

یک بازی مسابقه‌ای آرکید و سبک، در یک بزرگراه نئونی در شب. کنترلش ساده است و برای موبایل ساخته شده. موسیقی سینث‌ویو و همه‌ی صداهایش در لحظه با Web Audio ساخته می‌شوند.

**اجرا:** https://inneradev-tech.github.io/speedi/

## بازی

- در ترافیک جلو برو و به ماشین‌ها نزن. با اولین تصادف، دور تمام می‌شود.
- هر چه جلوتر بروی، سرعت و تراکم ترافیک بیشتر می‌شود.
- اگر از کنار یک ماشین از فاصله‌ی نزدیک رد شوی (**لایی**)، امتیاز اضافه و نیترو می‌گیری. لایی‌های پشت سر هم ضریب دارند.
- نیترو برای چند ثانیه سرعت را خیلی بالا می‌برد، ولی خطرش هم بیشتر است.

| | موبایل | کیبورد |
|---|---|---|
| فرمان | لمس نیمه‌ی چپ / راست صفحه | `←` `→` یا `A` `D` |
| نیترو | کشیدن انگشت رو به بالا یا دکمه‌ی N₂O | `Space` / `↑` |
| توقف | دکمه‌ی ⏸ | `Esc` / `P` |
| صدا | دکمه‌ی 🔊 | `M` |

## فنی

- فقط HTML، CSS و JavaScript خالص. بدون کتابخانه و بدون مرحله‌ی build.
- رندر شبه‌سه‌بعدی جاده روی Canvas 2D، با پیچ، سربالایی و مه. همه‌ی ماشین‌ها و اجزای صحنه در کد کشیده می‌شوند و هیچ فایل تصویری ندارد.
- موسیقی یک آهنگ حدوداً یک‌دقیقه‌ای و حلقه‌ای در لا مینور است، با کیک، باس، پد، آرپژ و ملودی. صدای موتور و دنده، باد، لایی، نیترو و تصادف هم ساخته می‌شوند.
- اگر دستگاه کُند باشد، رزولوشن رندر خودکار پایین می‌آید.
- با قفل شدن صفحه یا رفتن به تب دیگر، بازی خودکار متوقف می‌شود. رکورد در مرورگر ذخیره می‌شود.

| فایل | کار |
|---|---|
| `index.html` | صفحه و منوها |
| `style.css` | ظاهر رابط کاربری |
| `game.js` | موتور بازی، رندر و کنترل‌ها |
| `audio.js` | موسیقی و افکت‌های صوتی |

## انتشار روی GitHub Pages

1. در مخزن به **Settings → Pages** بروید.
2. در **Build and deployment**، گزینه‌ی **Source** را روی **Deploy from a branch** بگذارید.
3. شاخه (مثلاً `main`) و پوشه‌ی `/ (root)` را انتخاب کنید و ذخیره کنید.
4. بعد از حدود یک دقیقه، بازی در آدرس `https://<user>.github.io/<repo>/` در دسترس است.

برای اجرای محلی کافی است یک سرور ساده بالا بیاورید:

```bash
python3 -m http.server 8000
# سپس http://localhost:8000
```
