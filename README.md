# بازی‌خانه

مجموعه‌ای از بازی‌های کوچک، سبک و باکیفیت که برای موبایل ساخته شده‌اند. همه‌ی بازی‌ها مستقیم در مرورگر اجرا می‌شوند. تصاویر و موسیقی همه در کد ساخته می‌شوند و هیچ فایل تصویری یا صوتی ندارند.

**اجرا:** https://inneradev-tech.github.io/speedi/

| بازی | پوشه | توضیح |
|---|---|---|
| **SPEEDI** | [`speedi/`](speedi/) | مسابقه‌ی شبانه در بزرگراه نئونی؛ از بین ماشین‌ها لایی بکش. موسیقی سینث‌ویو. |
| **UNDEAD** | [`zombie/`](zombie/) | بقا در قبرستان تاریک؛ زامبی‌ها موج‌به‌موج می‌آیند. موسیقی تاریک و ترسناک. |
| **نوا** | [`nava/`](nava/) | بلوک‌های موسیقی؛ کاشی‌ها را بزن تا آهنگ ساخته شود. کلاسیک با پیانو، ایرانی با سنتور. |

## نوا

- هر کاشی که می‌زنی، نُت بعدی آهنگ را می‌نوازد. اگر کاشی را از دست بدهی یا جای خالی را بزنی، بازی تمام می‌شود.
- سه ستاره برای تمام کردن آهنگ است. بعد از آن، آهنگ دور بعد را سریع‌تر شروع می‌کند.
- **کلاسیک:** قطعه‌هایی با مالکیت عمومی، مثل سرود شادی و برای الیز از بتهوون، مینوئت در سل ماژور و چشمک بزن ستاره.
- **ایرانی:** قطعه‌هایی که برای خود بازی در دستگاه‌های شور، چهارگاه و ماهور ساخته شده‌اند، با صدای سنتور و ربع‌پرده‌ی واقعی.
- **آهنگ‌های من:** در خود بازی آهنگ بنویس. آهنگ فقط در مرورگر خودت ذخیره می‌شود.

نُت‌نویسی (برای `nava/songs.js` یا ویرایشگر داخل بازی):

| نوشتار | معنی |
|---|---|
| `C D E F G A B` + اکتاو | دو ر می فا سل لا سی، مثل `A4` |
| `#` / `b` | دیز / بمل |
| `k` / `s` | **کُرن** (ربع‌پرده پایین) / **سُری** (ربع‌پرده بالا)، مثل `Ek4` |
| `:2` `:0.5` `:1/2` | طول نُت نسبت به یک ضرب |
| `A4+D3` | آکورد، یعنی چند نُت هم‌زمان |
| `r:1` | سکوت |

کیبورد: `D` `F` `J` `K` چهار ستون را می‌زنند.

فقط آهنگ‌هایی را به مخزن اضافه کنید که آزادند: ترانه‌های محلی بی‌نام قدیمی، ساخته‌ی خودتان، یا قطعه‌هایی که مدت حق نشرشان تمام شده است. آهنگ‌های پاپ و سنتی معاصر حتی اگر دوباره نُت‌نویسی شوند، حق نشر دارند.

## SPEEDI

| | موبایل | کیبورد |
|---|---|---|
| فرمان | لمس نیمه‌ی چپ / راست صفحه | `←` `→` یا `A` `D` |
| نیترو | کشیدن انگشت رو به بالا یا دکمه‌ی N₂O | `Space` / `↑` |
| توقف / صدا | دکمه‌های بالای صفحه | `Esc` / `M` |

رد شدن از کنار ماشین‌ها از فاصله‌ی نزدیک (لایی) امتیاز و نیترو می‌دهد. هر چه جلوتر بروی، سرعت و ترافیک بیشتر می‌شود.

## UNDEAD

| | موبایل | کیبورد |
|---|---|---|
| حرکت | جوی‌استیک نیمه‌ی چپ صفحه | `WASD` / جهت‌ها |
| نشانه‌گیری و شلیک | جوی‌استیک نیمه‌ی راست صفحه؛ تا نگه داری شلیک می‌کند | موس برای نشانه‌گیری، نگه داشتن کلیک برای شلیک |
| پر کردن خشاب | خودکار وقتی خالی شود | `R` |
| توقف / صدا | دکمه‌های بالای صفحه | `Esc` / `M` |

- هر خشاب تعداد محدودی تیر دارد و پر کردنش زمان می‌برد، پس باید حساب‌شده شلیک کنی.
- روی موبایل یک کمک نشانه‌گیری ملایم هست: اگر تقریباً به سمت زامبی نشانه بگیری، تیر به او می‌رسد. لیزر قرمز هم جهت شلیک را نشان می‌دهد.

- سه نوع زامبی دارد: **معمولی**، **دونده** که سریع است و **غول** که کُند ولی پرجان است.
- بعد از هر موج سلاح قوی‌تر می‌شود: خشاب بزرگ‌تر، شلیک و پر کردن سریع‌تر، گلوله‌ی چندتایی، گلوله‌ی نافذ، سرعت و جان بیشتر.
- زامبی‌ها گاهی جعبه‌ی کمک‌های اولیه می‌اندازند.
- شب تاریک است. نور چراغ‌قوه، تیرهای چراغ برق و کدوهای روشن تنها روشنایی صحنه‌اند و چشم زامبی‌ها در تاریکی می‌درخشد.

## ساختار

```
index.html            صفحه‌ی اصلی مجموعه
speedi/               بازی ماشینی   (game.js, audio.js, style.css, index.html)
zombie/               بازی زامبی    (game.js, audio.js, style.css, index.html)
```

هر بازی مستقل است و فقط از HTML، CSS و JavaScript خالص استفاده می‌کند. هیچ کتابخانه یا مرحله‌ی build ندارد. برای افزودن بازی جدید کافی است یک پوشه‌ی جدید بسازید و یک کارت در `index.html` اضافه کنید.

## انتشار روی GitHub Pages

1. در مخزن به **Settings → Pages** بروید.
2. **Source** را روی **Deploy from a branch** بگذارید، شاخه را انتخاب کنید و پوشه را `/ (root)` بگذارید.
3. بعد از حدود یک دقیقه، مجموعه در `https://<user>.github.io/<repo>/` در دسترس است.

اجرای محلی:

```bash
python3 -m http.server 8000
# سپس http://localhost:8000
```
